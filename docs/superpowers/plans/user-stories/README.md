# User stories

The user stories are the north star of every feature's design: what each actor can do, and where each story stands. Each feature's plan in `docs/superpowers/plans/` has one stories file here, with the plan's date, and links to it rather than copying it. The template and its rules are in `agents.md`, at the repository root.

## Feature codes

Every story ID starts with its feature's code, so IDs stay unique across features (`WA.D5.SC.J1.A2`). Pick a new feature's code from letters not listed here, and add it when its stories file is created. A code never changes.
